# EC2 — Dia do Caos na Squad

## Projeto

Booka — Sistema SaaS de Agendamento Multifuncional Inteligente.

## Objetivo da Atividade

Esta pasta contém a entrega da atividade “O Dia do Caos na Squad — Simulação de Crise em Produção”, adaptada ao projeto Booka.

O objetivo da atividade é simular uma crise em produção e demonstrar como a equipe responde utilizando Scrum, Kanban, Gitflow, Pair Programming, Merge Conflict, Code Review, CI/CD, Postmortem e Retrospectiva.

## Cenário Adaptado

É sexta-feira, 16h30. A equipe Booka acabou de realizar o deploy de uma nova versão em produção. Cinco minutos depois, surgem alertas críticos: a rota de agendamento começa a falhar para parte dos usuários e o tempo de resposta das consultas de disponibilidade no banco de dados aumenta significativamente.

Os stakeholders cobram uma resposta imediata, pois prestadores de serviço estão perdendo possíveis agendamentos.

## Relação com o Desafio Original

No desafio original, a crise acontece em um sistema de e-commerce, com falha na rota de pagamento e aumento no tempo de resposta do banco de dados.

No Booka, a adaptação foi feita para uma falha no fluxo de agendamento, que é uma funcionalidade central do sistema. A lentidão no banco foi relacionada às consultas de disponibilidade de horários.

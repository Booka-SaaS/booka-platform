# Mini-retrospectiva — Dia do Caos no Booka

## O que funcionou bem

- A equipe conseguiu organizar as tarefas no Kanban.
- O Gitflow foi respeitado.
- A branch `hotfix/broken-checkout` foi utilizada corretamente.
- O Pair Programming ajudou na revisão da lógica.
- O Pull Request permitiu revisão cruzada antes do merge.

## Dificuldades encontradas

- A identificação da causa raiz exigiu análise conjunta entre backend e banco de dados.

- A equipe precisou revisar os arquivos para garantir que nenhuma credencial fosse exposta.

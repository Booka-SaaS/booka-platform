# Checklist do Kanban

- [ ] Project criado no GitHub Projects.
- [ ] Colunas criadas: Backlog, A Fazer, Em Desenvolvimento, Em Revisão, Testes, Concluído e Bloqueado.
- [ ] Cards cadastrados.
- [ ] Responsáveis definidos.
- [ ] Critérios de aceite definidos.
- [ ] Cards movimentados durante a execução.
- [ ] Cards bloqueados justificados.
- [ ] Cards concluídos validados pelo Product Owner.
- [ ] Evidências do Kanban registradas.

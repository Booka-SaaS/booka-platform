# Comparação de versões do BOOKA

Este monorepo utiliza como base:

- Frontend principal: https://github.com/TrueTrailBlazer/booka-frontend
- Backend principal: https://github.com/RubensGJ/BookaBackendV2

Versões alternativas para análise futura:

- https://github.com/Giullianoads/booka-frontend
- https://github.com/Giullianoads/booka-app

Essas versões alternativas não foram copiadas diretamente para evitar conflitos, duplicidade de estrutura e poluição no monorepo. Elas podem ser comparadas futuramente antes de migrar melhorias úteis.

Antes de qualquer migração futura, recomenda-se comparar:

- estrutura de rotas;
- serviços HTTP;
- modelos de autenticação;
- telas implementadas;
- dependências;
- scripts de build e execução;
- diferenças de contrato com o backend.

# Scrum no Booka

O Booka usa Scrum para organizar planejamento, execucao e validacao.

## Cerimonias

- Sprint planning: selecao de tarefas e criterios de aceite.
- Daily meeting: acompanhamento rapido de progresso e impedimentos.
- Sprint review: demonstracao do incremento entregue.
- Sprint retrospective: melhoria do processo da equipe.

## Papeis

| Papel | Responsabilidade |
| --- | --- |
| Product Owner | Priorizar valor, requisitos e aceite |
| Scrum Master | Facilitar ritos e remover bloqueios |
| Desenvolvedor Frontend | Angular, UI e integracao com API |
| Desenvolvedor Backend | Express, Prisma e regras de negocio |
| Banco de Dados | PostgreSQL/Supabase e migrations |
| Testes | Qualidade, E2E e validacao final |
| Documentacao | README, docs e relatorios |
| Deploy/DevOps | Render, Vercel, Supabase e variaveis |

## Definicao de pronto

Uma tarefa esta pronta quando o codigo compila, nao expoe segredos, possui documentacao quando necessario, foi revisada e passou pelos testes aplicaveis.
